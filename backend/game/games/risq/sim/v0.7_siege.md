Files are `v07_siege_<family>_<variation>.json`.
Variants 1/2/3 are conservative/balanced/assertive, with escort ramp scales 8/6/4 and building weights 0.5/1.0/1.5.
Support uses a bounded allocation; utility compares purchase efficiency; capability also derives infantry preferences and combat weights from definitions.
Utility and capability cap support shares at 40% and 45%, respectively, before escort and home-threat reductions.
Range receives a heuristic 1.25 value multiplier in purchase scoring; these estimates require simulator evaluation.
Shared changes cover production funding, enemy siege recognition, infantry scout selection and separate siege attacks.
Siege fires within its current space, targets military first, then buildings, and respects army retreats.

From `sim/`, regenerate one file with explicit approach, variant and output:
```bash
python3 tools/gen_v07_siege.py siege_approach=2 siege_variant=2 out=../config/ai/tmp/v07_siege_utility_balanced.json
```
